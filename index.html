Cores

Clique numa cor para copiar o código. Nos sites, use as variáveis do marca.css em vez do código.

Tipografia

Inter, variável (pesos 100 a 900), servida junto com o marca.css.

Logos

Logos de cada núcleo, na ordem do odisse.json. Os de uma cor (como o Estúdio 01) assumem a cor do texto ao redor quando colados no HTML.

Selos

Um selo por núcleo, em uma cor: Mão (Estúdio e posts únicos), Roda (Arquitetos), Flor (Objetos), Sol (Elaia).

Favicon

Dados institucionais

Lidos do odisse.json. Os sites leem o mesmo arquivo: mudou aqui, muda em todos.

Como usar

Cores e fonte, em qualquer site:

<link rel="stylesheet" href="https://marca.odisse.com.br/v1/marca.css">

body { font-family: var(--odisse-fonte); color: var(--odisse-tinta); }

Dados institucionais, por JavaScript:

const odisse = await fetch('https://marca.odisse.com.br/odisse.json').then(r => r.json());
link.href = odisse.contato.whatsapp_link;

Logos e favicon, direto pelo endereço:

<img src="https://marca.odisse.com.br/logos/logotipo-odisse.svg" alt="Odisse">
<link rel="icon" href="https://marca.odisse.com.br/favicon/favicon.svg" type="image/svg+xml">
